Concept A
Homepage Hero — Rotating Universe Art

Slides cross-fade every 4 seconds. Click the indicator dots to jump. Each universe has its own color tint overlay. The art slowly zooms out as it enters.

GRAND LINE

Art source: League + TFT slides use Riot Data Dragon splash URLs (already used in the project). Pokémon uses the PokeAPI official-artwork CDN. One Piece uses a stylized gradient until an art CDN is identified.
Performance: 4 images preloaded on the homepage. The next/prev slides are already decoded in the DOM, so cross-fades are instant with no re-download flash.
Dial back option: If the rotation feels too heavy, the hero can show only the active universe's art based on which hub the user last visited, defaulting to a generic gradient.
Concept B
Per-Universe Hub Page Backgrounds

Each universe hub gets its own rotating art behind the page header. The mini dots in the top-right show which art from that universe is active. Content stays fully readable via the gradient overlay.
